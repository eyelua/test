# Dark Crown Browser для Android

Браузер на движке Gecko (тот же, что в Firefox) через GeckoView. Чёрный интерфейс, твой логотип, всегда приватный режим.

## Что умеет

- **Приватный режим всегда:** куки, история, кэш и пароли не сохраняются на телефоне.
- **Защита:** строгая блокировка трекеров, изоляция сторонних куки, только HTTPS, защита от фишинга, блокировка опасных адресов (`javascript:`, `data:`, `file:`), запрет скриншотов и миниатюры в списке недавних приложений.
- **Вкладки** (кнопка с цифрой), всплывающие окна и вход через сторонние сервисы открываются во вкладке.
- **Быстрая очистка** и **Кнопка паники** (меню ⋮): паника стирает данные сайтов, закрывает все вкладки и полностью завершает процесс.
- Можно сделать браузером по умолчанию для ссылок.
- Своя стартовая страница с поиском DuckDuckGo.

**Чего пока нет:** скачивания файлов, меню по долгому нажатию на ссылку, расширений, менеджера паролей (это намеренно), камеры, микрофона и геолокации (запрещены).

## Как получить приложение (APK) через GitHub

1. Зарегистрируйся на https://github.com (бесплатно).
2. Создай репозиторий: «+» вверху справа → **New repository**, имя любое (например `darkcrown-android`), выбери **Private**, нажми **Create repository**.
3. Распакуй этот архив. На странице репозитория нажми **uploading an existing file** и перетащи туда **всё содержимое распакованной папки** (папки `app`, `.github` и файлы рядом с ними, а не внешнюю папку целиком). Внизу нажми **Commit changes**.
   - Если `.github` не загрузилась: нажми **Add file → Create new file**, в поле имени напиши `.github/workflows/android.yml`, вставь туда содержимое файла `android.yml` и сохрани.
4. Сборка начнётся сама. Открой вкладку **Actions**, выбери запуск **Build Dark Crown APK**. Если сборка не стартовала, нажми **Run workflow**. Ждать 5-10 минут.
5. Когда появится зелёная галочка, открой запуск и внизу в разделе **Artifacts** скачай **DarkCrown-APK**. Распакуй архив, внутри файл `DarkCrown.apk`.
6. Перекинь `DarkCrown.apk` на телефон и открой его. Android попросит разрешить установку из этого источника (в настройках: «Установка неизвестных приложений»). Если Google Play Protect предупредит, что приложение неизвестное, выбери «Всё равно установить»: приложение подписано твоим собственным ключом.

## Если сборка упала

Открой запуск с красным крестиком, нажми на шаг с ошибкой и пришли мне последние 50-80 строк текста. Или скачай артефакт **build-log** и пришли его. Приложение написано без возможности проверки на реальном телефоне и сборке, поэтому правки вероятны.

## Важно знать

- При каждой сборке создаётся новый ключ подписи, поэтому перед установкой новой версии **сначала удали старую** с телефона (данных в ней нет, всё приватное).
- Приложение не получает обновлений автоматически: чтобы обновить движок, запусти сборку заново (**Actions → Build Dark Crown APK → Run workflow**), она берёт самую свежую версию GeckoView.
- iPhone: сделать такую версию нельзя, Apple запрещает сторонние движки браузеров.
