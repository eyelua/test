# Dark Crown Browser

Приватный браузер на основе LibreWolf (а он — на Firefox). Свой логотип, тёмная тема с выбором цвета, встроенные функции, установщик `.exe`.

## Как получить DarkCrown-Setup.exe

1. Распакуй архив в любую папку.
2. Дважды кликни **`build-me.bat`**.
3. Скрипт сам скачает и поставит LibreWolf и Inno Setup, если их нет (Windows спросит разрешение — соглашайся), и соберёт установщик.
4. Готовый `DarkCrown-Setup.exe` появится на рабочем столе и в папке `dist`.

Если автоскачивание не сработало, скрипт скажет, какую программу поставить вручную:
- LibreWolf: https://librewolf.net/installation/windows/
- Inno Setup 6: https://jrsoftware.org/isdl.php

## Тема

При установке выбирается цвет акцента: золотой, фиолетовый, красный, зелёный или чёрный (чисто чёрный фон и светлый акцент). Позже его можно сменить, скопировав любой файл из `themes\` в `%APPDATA%\DarkCrown\Profile\chrome\accent.css`.

## Безопасность (версия 1.4)

Цель: чтобы токены, куки и пароли не лежали на диске, не утекали на другие сайты и не передавались автоматически.

**Что сделано в Dark Crown**
- **Токены не хранятся на диске.** Постоянный приватный режим: куки, сессии и кэш живут только в памяти и пропадают при закрытии. Это главная защита от программ-«стилеров», которые копируют файлы профиля браузера.
- **Токены не уходят на другие сайты.** Адрес-источник (Referer) урезается до домена, параметры вроде `?token=...` наружу не передаются; трекинг-параметры вырезаются из ссылок; сторонние куки изолированы полностью.
- **Пароли и автозаполнение выключены**, вход в аккаунт Firefox и синхронизация отключены (через синхронизацию данные уходят в облако), импорт данных из других браузеров отключён.
- **Автоматическая отправка учётных данных Windows сайтам выключена** (NTLM, Kerberos, Windows SSO).
- **Только защищённые соединения:** только HTTPS, не ниже TLS 1.2, смешанное содержимое блокируется, адреса-подделки (punycode) показываются явно.
- **Защита от фишинга** (главный способ кражи токенов): локальные списки вредоносных сайтов. Загрузки на проверку не отправляются. Отключается строкой `lockPref("browser.safebrowsing.phishing.enabled", false);` в `darkcrown.cfg`.
- **Расширения:** установка новых расширений запрещена (расширения — второй по частоте способ кражи токенов), остаются только встроенные: uBlock Origin, ClearURLs, Crown Tools. Убрать запрет: удали блок `InstallAddonsPermission` из `hardening-policies.json`.
- **Удалённая отладка отключена**, WebRTC не раскрывает локальный адрес.
- **Настройки заблокированы** (`lockPref` и политики): их нельзя изменить ни из интерфейса, ни подменой файлов профиля.
- **Папка программы закрыта от записи** обычному пользователю (только чтение и запуск; изменять могут только администраторы). Иначе программа без прав администратора могла бы подменить файл настроек. Это относится и к установке на другой диск.

**Другие браузеры на компьютере** (необязательно): `harden-browsers.bat` задаёт Chrome, Edge, Brave и Firefox политики безопасности (пароли и автозаполнение выключены, сторонние куки заблокированы, вход в аккаунт и синхронизация выключены, удалённая отладка закрыта, только HTTPS). `harden-browsers.bat blockext` дополнительно запрещает установку расширений, `harden-browsers.bat undo` снимает всё. Побочный эффект: перестанут сохраняться пароли и автозаполнение, а на некоторых сайтах сломается вход через сторонние куки.

**Чего это НЕ делает (честно)**
- Если на компьютере уже работает вредоносная программа с правами твоего пользователя, она может читать память браузера, перехватывать клавиши и делать снимки экрана. Против этого никакие настройки браузера не гарантируют защиту: нужен антивирус и осторожность с файлами.
- Фишинг, куда ты сам вводишь данные или токен, никакой браузер не остановит на 100%. Надёжнее всего защищают ключи безопасности и passkey: их нельзя ввести на поддельном сайте.
- Токен в оперативной памяти работает, пока сайт открыт. «Кнопка паники» стирает его, но вход на сайте при этом не отзывается: чтобы отозвать, выйди из аккаунта на самом сайте.

## Следы на компьютере

Браузер настроен так, чтобы не оставлять следов у тех, кто пользуется тем же компьютером:
- всегда приватный режим (история, куки, кэш и сессии не пишутся на диск);
- не запоминаются пароли, формы и поисковые подсказки из истории;
- списки «недавнее/частое» на значке в панели задач отключены;
- при закрытии всё дополнительно очищается;
- при удалении программы стирается и профиль (`%APPDATA%\DarkCrown`).

Чего это не скрывает: скачанные файлы остаются на диске, а провайдер, работодатель и сами сайты видят твой трафик и IP. Для этого нужен VPN или Tor.

## Интерфейс и картинки

- **Своя стартовая страница** (она же новая вкладка): тёмный фон, твой логотип, поиск DuckDuckGo и кнопки «Быстрая очистка» и «Кнопка паники». Работает через расширение Crown Tools, поэтому его нужно подписать (см. выше). Пока оно не подписано, на обычной новой вкладке всё равно подставляется твой логотип (`userContent.css`).
- **Логотип в окне «О браузере»** заменён на твой (`logo.css`).
- **Иконка** браузера на ярлыках, в меню «Пуск» и в установщике — твой логотип.
- Тёмная тема с выбором цвета (`userChrome.css`, `themes\`).
- Чтобы поменять картинку, замени `logo.png` и запусти `python build-assets.py` (нужен Python и `pip install pillow`), потом `build-me.bat`.

Что пока остаётся от LibreWolf: название «LibreWolf» в заголовке окна и значок самой программы в заголовке окна. Это зашито в архивы браузера; менять это можно только пересборкой браузера из исходников (путь `build.sh`).

## Новые функции (версия 1.3)

- **Скрыть окна** (`Alt+Shift+H` или кнопка на стартовой странице): сворачивает все окна браузера.
- **Автоочистка при бездействии**: если 15 минут ничего не трогать, куки, кэш и хранилище стираются сами.
- **Установка на диск с наибольшим свободным местом**: установщик сам предлагает диск, где больше всего места (только жёсткие диски, не флешки). Папку можно сменить в окне установки.
- **Быстрая сборка**: сжатие переключено на быстрый режим, установщик собирается за пару минут (он станет чуть больше).
- **Иконка и имя самого браузера** заменяются на твои (в окне, панели задач, диспетчере задач). Это делается необязательным шагом: если не получилось, браузер остаётся рабочим, но с прежней иконкой.

## Функции (расширение Crown Tools)

- **Кнопка паники** (иконка на панели или `Ctrl+Shift+K`): стирает данные, закрывает все окна, открывает чистое.
- **Быстрая очистка** (`Ctrl+Shift+L`): куки, кэш и хранилище, вкладки остаются.
- **ClearURLs**: убирает трекинг из ссылок. uBlock Origin уже встроен в LibreWolf.

Важно: расширение Crown Tools нужно один раз подписать на https://addons.mozilla.org/developers/ (загрузить как «самостоятельное распространение», бесплатно), иначе браузер его не загрузит. Подписанный файл положи вместо `crowntools.xpi` и запусти `build-me.bat` снова.

## Файлы

| Файл | Назначение |
|---|---|
| `build-me.bat` | запуск автосборки |
| `hardening-policies.json` | политики безопасности Dark Crown |
| `harden-browsers.bat`, `.ps1` | необязательно: политики для Chrome, Edge, Brave, Firefox |
| `make-installer.ps1` | сама автосборка |
| `darkcrown.iss` | описание установщика |
| `darkcrown.cfg` | настройки приватности и вида |
| `userChrome.css`, `themes\` | тёмная тема и цвета акцента |
| `crown-tools\`, `crowntools.xpi` | расширение с функциями |
| `logo.png`, `icon.ico`, `icons\` | логотип и иконки |
| `build-assets.py` | пересборка иконок и расширения из `logo.png` |
| `build.sh`, `find-name.sh` | полная сборка из исходников (для опытных) |
| `.github\` | автосборка на GitHub (необязательно) |

## Обновления

Автообновлений нет: когда выходит новая версия LibreWolf, запусти `build-me.bat` снова (после обновления LibreWolf на своём ПК), чтобы пересобрать установщик на свежей базе.
